# 镜流 Frameflow 隐私说明

更新日期：2026 年 11 月

镜流 Frameflow（下称“本软件”）是在你电脑上运行的桌面软件。你的工程、素材和导出的视频都保存在你自己的电脑上。我们没有账号系统，也没有自己的服务器，不收集你的个人信息。

## 我们不做的事

- 不收集使用统计，不做遥测，不放广告。
- 不会把你的工程、素材或视频上传到我们这里。
- 程序出错时只在本机记录日志，不会自动上报。
- 不会在后台自动检查或下载更新。

## 保存在你电脑上的数据

- **设置与密钥**：保存在 `%APPDATA%\Frameflow`。其中 `settings.json` 是设置；`secrets.json` 是你填写的 API Key，用 Windows 系统提供的加密功能加密保存，只有当前 Windows 用户能解开。
- **运行日志**：保存在 `%APPDATA%\Frameflow\logs`，用于排查问题。写入日志前会把 API Key、授权凭据和你的用户目录名替换成占位符。只有你主动发送时，别人才能看到。
- **按需下载的工具和模型**：yt-dlp、whisper.cpp 以及语音识别模型保存在 `%APPDATA%\Frameflow` 下的 `bin`、`models` 文件夹。
- **工程与素材**：默认保存在 `文档\Frameflow`（可以在设置里修改），包括工程、素材库、拆片分析，以及缩略图、波形和预览文件等缓存。
- **临时文件**：处理视频时会用到系统临时文件夹下的 `frameflow` 文件夹，可以随时清理。

卸载本软件时默认会保留这些数据，方便重新安装后继续使用。如果你想彻底删除，请在卸载后手动删除上面列出的文件夹。

## 什么时候会联网

只有当你使用下面这些功能时，本软件才会联网，而且只把完成这项功能所需的内容发给对应的服务：

- **AI 文案、导演助手、拆片分析**：把你输入的文字、工程的相关描述，以及你选中画面的截图，发送到你在设置中选择的 AI 服务（默认 OpenAI，也可以改成其它兼容服务的地址）。如果你选择通过本机的 Codex 命令行工具使用 ChatGPT 登录，内容会经由该工具发送给 OpenAI。
- **AI 出图**：把画面描述（提示词）和你选择的参考图片，发送给你在设置中选择的出图服务：火山方舟（火山引擎的模型服务，用的是即梦 Seedream 图片模型），或 OpenAI 兼容接口。
- **云端语音转文字**：把从视频中提取的音频上传到 OpenAI 的语音识别接口（或你设置的兼容服务）。如果你选择**本机识别**，第一次使用时会从 GitHub 下载 whisper.cpp、从 Hugging Face 下载语音模型，之后识别完全在本机进行，音频不会离开你的电脑。
- **素材搜索与下载**：把你输入的搜索词发送给下面这些不需要 API Key 的免费素材库：维基共享资源（Wikimedia Commons）、Openverse、互联网档案馆（Internet Archive）、NASA 图片与视频库。Pexels 和 Pixabay 只有在你自己填写了它们的 API Key 之后才会访问，不填就不会连接。搜索结果里的预览图和你选中的素材，会从这些素材库各自的服务器（或它们使用的内容分发网络）下载。
- **视频链接下载与视频站搜索**：第一次使用时从 GitHub 下载 yt-dlp；之后按你提供的链接或搜索词访问对应的视频网站（例如 YouTube、哔哩哔哩）。
- **AI 视频生成**：把你填写的提示词和你选择的参考图片，发送给你选择的视频生成服务：火山方舟（即梦 Seedance 视频模型）、火山引擎的即梦AI、快手可灵、MiniMax 海螺、Runway、Google Veo、OpenAI Sora、Luma、fal.ai。
- **打开网页链接**：在帮助、许可等页面点击链接时，会用你的默认浏览器打开。

这些第三方服务会按照它们自己的隐私政策和服务条款处理你发送的内容，费用由你和服务商直接结算。请只发送你有权使用的内容，并在使用前阅读对应服务的条款。

## 你的控制权

- 不填写 API Key、不使用上面的联网功能，本软件也能离线完成剪辑和导出。
- 你可以随时在设置里删除已保存的 API Key。
- 你可以随时删除工程、素材库、缓存和日志文件夹。

## 儿童

本软件不面向 14 周岁以下的儿童，也不会有意收集儿童的个人信息。

## 变更

本说明如有变化，会随新版本一同更新，并在更新说明中提示。
